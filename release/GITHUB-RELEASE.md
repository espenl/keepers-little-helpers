Adds material tracking, independent settings in the pause menu, and a preview for moving idle structures. Building rows now reserve space for counts and the Shift-click hint; garden counts include planted plots.

- **Track materials:** Shift-click a blueprint; click the panel's X to clear.
- **Configure:** Esc > Keeper's Little Helpers.
- **Move (preview):** select Move at a desk, select an idle structure, and choose a valid spot in the same area. Right-click cancels.

Moving supports normal yard workstations and recalculates nearby tool-rack links. Active work, assigned workers, fitted attachments, planted beds, and special structures remain restricted. Back up saves before trying this preview. New moving/UI behavior has limited gameplay coverage; 419 automated checks cover the existing count/reminder rules.

Requires BepInEx 5.4.23.5 x64, installed separately. Close the game and extract the ZIP over your existing installation. Keep only one plugin DLL.
